# PLITAP · Приложение

Пользовательское приложение для создания, просмотра, получения, хранения и передачи плиток.

**Этап:** Опубликована структура направления. Реализация и содержательные материалы будут добавляться отдельными изменениями.

[Карта проекта](https://github.com/Plitap/Plitap/blob/main/REPOSITORIES.md) · [Общие правила участия](https://github.com/Plitap/.github/blob/main/CONTRIBUTING.md)

## Назначение

- Пользовательские сценарии, интерфейс и настройки приложения.
- Интеграция общих протокольных и сетевых компонентов.
- Платформенные возможности, хранение ключей и подготовка выпусков.

## Границы направления

Общие проверки и сетевые механизмы развиваются в [core](https://github.com/Plitap/core), [network](https://github.com/Plitap/network) и [sdk](https://github.com/Plitap/sdk). В этот репозиторий пока не перенесён существующий прототип. Выбор технологической основы и список поддерживаемых платформ будут указаны при публикации реализации.

## Структура

| Раздел | Назначение |
|---|---|
| [`app/`](app/) | Исходники приложения и файлы выбранного технологического стека. Сейчас здесь только описание назначения. |
| [`assets/`](assets/) | Материалы интерфейса приложения. Общий бренд задаётся в design. |
| [`tests/`](tests/) | Проверки поведения приложения и его интеграции с общими компонентами. |
| [`docs/`](docs/) | Устройство приложения, инструкции разработки и сведения о выпусках. |

Каждый раздел сейчас содержит README с его назначением. Названия разделов не обозначают готовую функцию или выбранную технологию.

## Участие

Вопросы об этом направлении и конкретные задачи — в [Issues](https://github.com/Plitap/client/issues). Общие идеи — в [обсуждениях PLITAP](https://github.com/Plitap/Plitap/discussions).

Предложение должно объяснять задачу, ожидаемый результат и связанные компоненты. Рабочее обсуждение, принятое правило и опубликованная реализация имеют разные статусы.

## Условия использования

Лицензии для кода, спецификации и визуальных материалов определяются отдельно. См. [статус лицензирования](https://github.com/Plitap/.github/blob/main/LICENSING.md).
